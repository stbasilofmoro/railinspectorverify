The signal aspect

Wayside signals already encode exactly the logic this tool needs, so the verdict is not styled as a generic alert — it is styled as a lamp. Red means work is required before ties move; green means the railroad accepts its own inspection; amber means a human has to call. These three hues are reserved for verdicts and appear nowhere else in the interface.

Ground and ink

The page commits to a single dark world rather than shipping a light theme. Glow is the entire visual argument, and glow needs darkness to read — a light variant would land as a different product. Type

Archivo carries headings — a grotesque with the squared-off weight of railroad signage and equipment lettering. Instrument Sans handles reading text. JetBrains Mono is reserved for the industry's own fixed-width vocabulary: AAR reporting marks, FRA network codes, coordinates. Mono here is data, not decoration.

How the glow is built

Three techniques, used consistently. Everything that appears to emit light is one of these — no drop shadows stamped on arbitrary elements, and no glow on anything that is not either interactive or a verdict.

Masked gradient edge

A hairline that runs through the full ramp. The element paints a gradient, then masks out everything but a 1px frame. Rotating the conic makes the edge travel.

padding:1px; background:conic-gradient(...); mask:linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0); mask-composite:exclude;

Stacked colored shadow

Three shadows at increasing blur and decreasing opacity, each a different hue. The overlap reads as a gradient halo rather than three separate rings.

box-shadow: 0 0 22px rgba(139,92,246,.62), 0 0 46px rgba(34,211,238,.34), 0 0 88px rgba(232,121,249,.24);
NET=I

Bloom behind the object

A blurred radial sibling sits behind the element and breathes. This is how the search field lights when focused and how each signal lamp carries its aspect into the surrounding dark.

filter:blur(30px); background:radial-gradient(circle, var(--a2),transparent 66%); animation:breathe 5s ease-in-out infinite;

Motion and restraint

Fluidity comes from a few slow, continuous fields rather than many short entrance animations. Nothing waits on a scroll observer, so the page is whole the moment it paints.

AMBIENT

Slow and unsynchronized

Aurora fields run 34–47s on mismatched cycles. Long enough that the movement is felt rather than watched.

RESPONSE

Motion answers an action

Focus, hover, and the lamp lighting on a result. Transitions stay at .22s–.35s; anything slower feels broken.

ARRIVAL

One orchestrated moment

The verdict lamp ignites once — bloom scales from 0.8 while opacity rises. It is the only entrance animation in the product.

OPT OUT

Reduced motion is total

prefers-reduced-motion halts every animation and transition. The lamp still glows; it simply arrives already lit.

Rules that keep it honest

COLOR

Aspect color is never decorative

Red, amber, and green appear only on a verdict. If an element is not answering the inspection question, it uses aurora or ink.

CONTRAST

Glow is not the signal

Every aspect pairs its lamp with a word — STOP, CLEAR, APPROACH, DARK — so the verdict survives color blindness and a bright screen.

GLOW

Light means live

Only interactive controls and verdicts emit. Static panels get a masked edge at most, which is why the edge reads as structure.

CERTAINTY

Amber is a real answer

The tool is allowed not to know. Short-line coverage is genuinely uneven, and a confident wrong answer costs a shipper more than an honest handoff.
